# Certificates Folder

This folder contains all certification documents and achievement proofs.

## Instructions

Please add your certificate files here. Supported formats:
- PDF files
- Image files (PNG, JPG, JPEG)

## Naming Convention

For better organization, please name your files as:
- `[Platform]_[Course/Certificate Name].pdf`
- Example: `Coursera_Machine_Learning.pdf`
- Example: `Udemy_React_Complete_Guide.pdf`

## Categories

Organize your certificates by category:
- **AI/ML**: TensorFlow, PyTorch, Machine Learning, Deep Learning
- **Web Development**: React, Node.js, Full Stack Development
- **Cloud**: AWS, Azure, Google Cloud
- **Data Science**: Data Analysis, Data Visualization, Statistics
- **Other**: Any other relevant certifications

---

Your certificates will be showcased in the Achievements section of the portfolio.
